Arquitectura Bajá
Supabase + React Native / Flutter
Flujo de datos
1
Inicio de viaje
App crea registro en trips → activa GPS background service → inicia cálculo Haversine local cada N segundos (adaptativo: 30s lejos, 3s cerca)
2
Monitoreo
GPS local calcula distancia → si cruza umbral, dispara alerta nativa (vibración/sonido/notificación) → loguea en trip_alerts → si compartió viaje, actualiza shared_trips via Realtime
3
Detección de parada pasada
Si la distancia empieza a crecer después de haber bajado de 500m → activa pantalla "Te pasaste" → trip.status = 'missed'
4
Llegada
Distancia < 50m → alarma final (swipe to dismiss) → end_trip('arrived') → pide rating → desactiva shared_trips
